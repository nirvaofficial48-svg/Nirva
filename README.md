# Nirva

A calm, private web browser built on Firefox.

## Download

**[Download the latest version for Mac](../../releases/latest)** (macOS 12 Monterey or newer,
Apple Silicon and Intel).

Open the .dmg, drag Nirva onto Applications. The first time, macOS asks you to confirm: open
**System Settings → Privacy & Security** and click **Open Anyway** next to Nirva.
